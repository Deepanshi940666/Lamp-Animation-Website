# Lamp Animation Website

A simple and interactive web page where you can click on a lamp to switch the background light **ON** and **OFF**.

### 🔥 Features
- Click the lamp to toggle between light and dark mode
- Smooth animation effect for background change
- Easy and fun interaction for beginners

### 📌 How it works
When the user clicks on the lamp image:
- The background becomes **dark**
- Clicking again makes it **bright**
- It simulates a light being switched on/off 😊
